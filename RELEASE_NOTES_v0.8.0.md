# Instalación

Reemplazar el proyecto o copiar los archivos modificados. Luego ejecutar:

```bash
flutter clean
flutter pub get
flutter run
```

## Pruebas
- Crear y editar una reparación.
- Completar mantenimiento.
- Agregar foto y evidencia.
- Editar vehículo.
- Revisar filtros, comparador y reproductor.
