# EN store listing

**Title:** Project Garage

**Short description:** Manage restoration work, maintenance, photos, costs and local backups.

**Full description:** Project Garage organizes vehicle restoration projects on your device. Track the vehicle, workshop tasks, maintenance, logbook, photos, receipts and budget. Export backups and create PDF reports. The app works offline and stores data locally; cloud synchronization is not provided.
# Visual identity

Project Garage combines technical documentation, visible progress, and a focused graphite interface designed for real restoration projects.
