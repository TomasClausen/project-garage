# Project Garage v0.7.0 — Home Pro

## Archivos incluidos

- lib/screens/home_screen.dart
- pubspec.yaml
- CHANGELOG.md

## Instalación

Copiar el contenido del ZIP sobre la raíz del proyecto y aceptar reemplazos.

Luego ejecutar:

```bash
flutter clean
flutter pub get
flutter run
```

## Qué probar

1. Abrir Inicio.
2. Revisar el hero con y sin fotografía.
3. Verificar los conteos de reparaciones, mantenimientos y evidencias.
4. Tocar Próximo objetivo y confirmar que abre el detalle.
5. Tocar Mantenimiento y confirmar la navegación.
6. Revisar el cálculo de inversión.
7. Confirmar la última evidencia.
8. Revisar alertas con reparaciones de prioridad alta y mantenimientos vencidos.
9. Probar en una pantalla angosta para detectar overflow.
