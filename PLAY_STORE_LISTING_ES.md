# Ficha ES

**Título:** Project Garage

**Descripción corta:** Gestioná restauraciones, mantenimiento, fotos, gastos y backups sin nube.

**Descripción completa:** Project Garage organiza proyectos de restauración vehicular desde el teléfono. Registrá vehículo, trabajos, mantenimiento, bitácora, fotos, comprobantes y presupuesto. Exportá backups y generá informes PDF. La aplicación funciona offline y conserva los datos localmente; no ofrece sincronización cloud.
# Identidad visual

Project Garage combina documentación técnica, progreso visible y una interfaz grafito sobria diseñada para acompañar proyectos de restauración reales.
