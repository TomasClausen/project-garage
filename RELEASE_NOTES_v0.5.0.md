# Project Garage v0.5.0 — Evidencias de reparación

## Instalación

Reemplazar los archivos incluidos respetando la estructura de carpetas.
No hace falta ejecutar build_runner: el adaptador RepairMedia ya está incluido.
Luego ejecutar un hot restart completo.

## Pruebas

1. Abrir una reparación y entrar en Evidencias.
2. Agregar imágenes desde cámara y galería.
3. Probar todas las etapas.
4. Abrir una imagen y verificar zoom.
5. Mantener presionada una imagen y eliminarla.
6. Cerrar y volver a abrir la app para confirmar persistencia.
7. Verificar que el contador del detalle se actualice.

## Alcance

Esta versión admite evidencias basadas en imágenes. Los comprobantes se guardan como foto.
La importación de PDF queda fuera de v0.5.0.
