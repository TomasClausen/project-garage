# Project Garage 1.0.0 — Public Release

Las instalaciones nuevas comienzan vacías y guiadas; las actualizaciones preservan datos existentes. Los datos siguen siendo locales y controlados por el usuario.

El package ID público definitivo es `com.projectgarage.app`. Android e iOS consideran aplicaciones distintas tanto los builds `com.example` anteriores como cualquier build provisional con otro identificador.

La versión pública estrena Project Garage Design System 2.0: identidad grafito/bordó, logo hexagonal oficial, progreso técnico segmentado, tarjetas sobrias, navegación lineal y motion accesible.
