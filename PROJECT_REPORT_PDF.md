# Informe PDF

Permite elegir título, costos, comprobantes, fotos, máximo de fotos, trabajos y
orientación. Incluye portada, vehículo, reparación, mantenimiento, finanzas,
presupuesto, bitácora y resumen. El límite es 100 fotos y el default 20.

El documento se comprime y advierte cuando supera 50 MB.
