# Project Garage v0.9.0+15 — Finance Pro

Finance Pro convierte Finanzas en un centro de control del presupuesto y la
inversión de la restauración. Permite registrar movimientos con comprobantes,
pagos parciales, proveedor y vínculos a trabajos o mantenimientos; muestra deuda,
disponibilidad, sobrecosto, categorías y evolución mensual.

La adopción es segura: los costos existentes siguen visibles como legacy y sólo
se importan cuando el usuario lo confirma. No se modifican reparaciones,
mantenimientos ni datos Hive anteriores.

Consultar `FINANCE_DOMAIN.md` para reglas de cálculo y `MIGRATION_v0.9.0.md`
para compatibilidad.
