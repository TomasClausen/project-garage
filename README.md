# Project Garage

Project Garage es una aplicación Flutter para gestionar y documentar proyectos
de restauración y mantenimiento de vehículos.

## Estado

Versión actual: v0.8.6+13 — UX Polish Release.

## Tecnologías

- Flutter
- Provider
- Hive CE

## Validación local

```bash
flutter format .
flutter analyze
flutter test
flutter build apk --debug
```
